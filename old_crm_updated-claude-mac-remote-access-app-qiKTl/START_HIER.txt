📦 SCHNELLSTART
═══════════════════════════════════════════════════════════

1️⃣  ZIP entpacken:
   unzip mac_assistant_v2.0_complete.zip

2️⃣  Setup ausführen:
   cd mac_assistant
   chmod +x setup.sh
   ./setup.sh

3️⃣  API Key setzen:
   export ANTHROPIC_API_KEY='sk-ant-your-key-here'

4️⃣  App starten:
   source venv/bin/activate
   python3 main.py

🎯 WAS KANN DIE APP?

✅ Plugin-System - Einfach neue Apps hinzufügen
✅ KI-Automation - Tasks in natürlicher Sprache
✅ Zeitreise - "Was habe ich vor 3 Tagen gemacht?"
✅ Multi-App - Mail, Slack, Viber, Telegram, Photos
✅ Task Execution - Einfache & Multi-Step Tasks

═══════════════════════════════════════════════════════════

📱 VERFÜGBARE PLUGINS

• Mail.app - E-Mails lesen, senden, durchsuchen
• Slack - Nachrichten, Channels, Status
• Viber - Nachrichten senden & empfangen
• Telegram - Messaging
• Photos - Fotos suchen, löschen, organisieren

...und du kannst BELIEBIGE weitere Apps hinzufügen!
